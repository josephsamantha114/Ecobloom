# EcoBloom VS Code starter

1. Open this folder in VS Code.
2. In Terminal, run `npm install`.
3. Run `npm run dev`.
4. Open the localhost URL printed in the terminal.

This is the user-supplied Framer component adapted for a standalone React/Vite app. The Framer-specific imports/property controls were removed; the existing scroll behavior and styles were preserved. Images currently use external framerusercontent.com URLs and require internet access. The original component is only the homepage, not a complete multi-page site.
